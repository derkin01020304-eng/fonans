# FinanceAssistantAPI и MCP

## Разрешения

Сервер выключен по умолчанию. **Настройки → Подключение AI через MCP**: выберите конкретные инструменты и подтвердите выдачу токена на 15 минут. Для записи флажки изначально выключены.

Токен позволяет выполнить только выбранные инструменты. Разрешение на запись — заранее подтверждённая ограниченная делегация; каждое повторное действие с таким токеном не вызывает диалог на телефоне. Во встроенном локальном помощнике запись подтверждается отдельной формой.

Токены случайные, хранятся только в памяти и отзываются при блокировке, уходе в фон или остановке сервера. Через две минуты без действий экран блокируется. Поддерживайте приложение открытым при работе с MCP; авторазблокировка для AI не предусмотрена.

## HTTP через USB

Включите отладку USB на своём Android-устройстве, подключите его к компьютеру и подтвердите компьютер на телефоне:

    adb devices
    adb forward tcp:8765 tcp:8765

На телефоне включите MCP и выдайте токен. Endpoint: `http://127.0.0.1:8765/mcp`.

Транспорт: Streamable HTTP в режиме JSON-ответов, протокол `2025-06-18`. Поддерживаются initialize, notifications/initialized, ping, tools/list и tools/call. GET отвечает 405: SSE не используется. Сервер stateless, отдельного MCP session ID нет. Он слушает только loopback IPv4, отклоняет Origin и чужой Host, принимает максимум 64 КиБ на запрос.

Все запросы, включая initialize, требуют:

    Authorization: Bearer <токен из приложения>
    Content-Type: application/json
    Accept: application/json, text/event-stream
    MCP-Protocol-Version: 2025-06-18

Инициализация:

    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "initialize",
      "params": {
        "protocolVersion": "2025-06-18",
        "capabilities": {},
        "clientInfo": {"name": "my-finance-client", "version": "1.0"}
      }
    }

Список разрешённых инструментов:

    {"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}

Баланс и идентификаторы счетов:

    {
      "jsonrpc": "2.0",
      "id": 3,
      "method": "tools/call",
      "params": {"name":"get_balance","arguments":{"currency":"RUB"}}
    }

Запись расхода:

    {
      "jsonrpc": "2.0",
      "id": 4,
      "method": "tools/call",
      "params": {
        "name": "add_expense",
        "arguments": {
          "requestId": "expense-unique-client-uuid",
          "accountId": "card",
          "amountMinor": 45000,
          "currency": "RUB",
          "category": "Еда"
        }
      }
    }

amountMinor — целое число копеек, не рублей. accountId получайте из get_balance. Пример `card` существует в новом стандартном учёте, но банк и пользовательские счета имеют другие ID.

requestId обязателен для любой записи. Повтор того же инструмента с теми же аргументами возвращает сохранённый результат без второй записи. Повтор requestId с изменёнными аргументами отклоняется. Результат, проводка и запись идемпотентности сохраняются в одной SQLite-транзакции.

## Stdio для клиента без HTTP

Включён `scripts/mcp_bridge.py`: Python 3.10+, только стандартная библиотека. Он читает JSON-RPC по строкам stdin и пересылает его на локальный HTTP endpoint; stdout используется только для ответов протокола.

Внешний клиент запускает:

    python3 /absolute/path/derk_finance/scripts/mcp_bridge.py

Передайте токен в переменной окружения `DERK_MCP_TOKEN` процесса клиента. Не помещайте токен в общий репозиторий и командные аргументы. Настройка большинства stdio-клиентов имеет такую форму:

    {
      "mcpServers": {
        "derk-finance": {
          "command": "python3",
          "args": ["/absolute/path/derk_finance/scripts/mcp_bridge.py"]
        }
      }
    }

Клиент должен унаследовать DERK_MCP_TOKEN из окружения; если он запускает MCP с очищенным окружением, используйте его локальное защищённое поле env. Точный формат подключения зависит от клиента. Windows может использовать `python` вместо `python3`.

После окончания:

    adb forward --remove tcp:8765

На телефоне нажмите «Остановить сервер и отозвать доступ».

## Инструменты

Полные входные JSON Schema лежат в `assets/mcp_tools.json` и выдаются tools/list.

| Инструмент | Доступ | Назначение |
|---|---|---|
| get_balance | Чтение | Баланс, свободные деньги, резервы и счета |
| get_summary | Чтение | Период, доходы, расходы, категории, средние значения |
| get_transactions | Чтение | Операции с фильтрами и пагинацией |
| search_transactions | Чтение | Поиск по тексту, категории и датам |
| add_income | Запись | Доход, источник, рабочие минуты |
| add_expense | Запись | Расход, категория, получатель |
| add_debt | Запись | Существующий долг; без автоматического движения денег |
| update_debt | Запись | Имя/комментарий/срок и необязательное частичное погашение |
| get_debts | Чтение | Оба направления, прогресс и статус |
| add_credit | Запись | Существующий кредит или рассрочка |
| get_credits | Чтение | Остатки, платежи и оценка процентов |
| add_savings | Запись | Перевод в накопления или обратно, с необязательной целью |
| create_goal | Запись | Новая цель |
| update_goal | Запись | Изменение параметров цели |
| get_goals | Чтение | Цели, остаток и дневной план |
| get_upcoming_payments | Чтение | Ближайшие сроки платежей, кредитов и долгов |

get_transactions/search_transactions: limit по умолчанию 100, максимум по схеме 500; offset задаёт сдвиг. to — исключительная верхняя граница. Даты с часовым поясом переводятся в локальное время устройства.

get_upcoming_payments возвращает ближайший срок каждого обязательства, включая просроченные. Полный развёрнутый календарь всех повторений пока не является отдельным API-инструментом; расчёт свободного остатка учитывает повторения.

## Граница транспорта

Это локальный доверенный pairing с пользовательским bearer-токеном. Здесь нет remote OAuth authorization server, публичного HTTPS endpoint или доступа по Wi-Fi. Для удалённого MCP нужен отдельный защищённый gateway с полноценной авторизацией; пробрасывать порт в интернет не следует.

Внешний AI-клиент может отправлять полученные данные своей модели. Решение о провайдере модели и о передаче финансовых данных пользователь принимает при подключении клиента.

Спецификации: [MCP transports](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports), [MCP authorization](https://modelcontextprotocol.io/specification/2025-06-18/basic/authorization).
